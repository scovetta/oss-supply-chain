# Book 2: Protecting the Software Supply Chain

Knowing how supply chain attacks work is only useful if it changes what you do. This book is about defenses: the controls, tools, and processes that reduce your exposure, from the moment someone proposes adding a dependency to the moment code runs in production.

It starts with measurement: how to assess risk in a dependency graph, build an accurate inventory with SBOMs, and understand the limits of vulnerability databases. It then covers dependency management (vetting, pinning, updating, and reducing what you depend on) and security testing that reaches beyond your own code. The middle chapters harden the places attackers actually go: developer workstations, CI/CD pipelines, build provenance and signing, registries, and deployment. The later chapters cover what to do when prevention fails, including detection, containment, recovery, and communication, and how to turn all of this into a security program and a platform that makes the secure path the easy one.
